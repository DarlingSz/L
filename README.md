# 🚗 Lava Jato JB — Sistema de Agendamento Online

![Preview](logo%20lvajato%20jb%20preto.png)

## ✨ Sobre o Projeto

Sistema moderno de agendamento online desenvolvido para o **Lava Jato JB**, permitindo que clientes realizem marcações de serviços diretamente pelo WhatsApp de forma rápida, prática e profissional.

O projeto possui:

* Interface moderna e responsiva
* Integração direta com WhatsApp
* Mapa incorporado do Google Maps
* Serviços personalizados
* Layout otimizado para celulares
* Tema dark premium
* Informações de pagamento e localização

---

# 🛠 Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript
* Google Maps Embed
* WhatsApp API
